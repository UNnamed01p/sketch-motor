# Sketch Motor

Arduino에서 서보모터를 제어하는 간단한 예제 프로젝트입니다. 전원이 켜지면 D12 핀에 연결된 서보모터에 `170°` 이동 명령을 한 번 전달합니다.

## 파일 구성

- `sketch_motor.ino`: Arduino 서보모터 제어 코드
- `servo_simulator.html`: 동작을 화면으로 표현하기 위한 웹 시뮬레이터
- `CHANGELOG.md`: 커밋별 주요 변경 내용 기록

## 동작 방식

1. `setup()`에서 D12 핀에 서보모터를 연결합니다.
2. `motor1.write(170)`으로 목표 각도를 설정합니다.
3. `loop()`에는 반복 동작이 없으므로 서보모터는 추가 명령을 받지 않습니다.

## 하드웨어 연결

| 서보모터 선 | 연결 위치 |
| --- | --- |
| 신호 | Arduino D12 |
| 전원 | 5V 전원 |
| 접지 | Arduino와 전원의 공통 GND |

서보모터의 소비 전류가 크면 Arduino의 5V 핀 대신 별도 5V 전원을 사용하세요. 별도 전원을 사용할 때는 Arduino와 전원의 GND를 서로 연결해야 합니다.

## 실행

1. Arduino IDE에서 `sketch_motor.ino`를 엽니다.
2. 사용하는 보드와 포트를 선택합니다.
3. 스케치를 컴파일하고 보드에 업로드합니다.

## 참고 사항

- 목표 각도와 핀 번호가 코드에 고정되어 있습니다.
- 웹 시뮬레이터는 실제 Arduino 보드와 통신하지 않는 시각적 모형입니다.
